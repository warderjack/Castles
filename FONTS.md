# Fonts used by the port

The original game draws text with the classic Mac system fonts (Chicago 12 for menus, Geneva 9 for body text, Helvetica 18 bold for the map header). Those fonts live in the Mac System file (Apple's) and are not included here. The port uses these free stand-ins:

| Original | Stand-in | Author | License |
|---|---|---|---|
| Chicago 12 (menus, copyright line) | **ChicagoFLF** (pixel font) | Robin Casady (after Susan Kare's Chicago) | Public domain: the author's note embedded in the font says "You are free to use them as you wish. I consider those two in public domain." (the font is also listed under the SIL Open Font License 1.1 by some catalogues, e.g. usemodify.com) |
| Geneva 9 (body, dialogs, credits) | **Geneva 9** (FontStruct) | Kelsey Higham, http://fontstruct.fontshop.com/fontstructions/show/349277 | Creative Commons Attribution 3.0 (https://creativecommons.org/licenses/by/3.0/): free to share and adapt with credit |
| Helvetica, Times, Courier-style text | Liberation Sans / Serif / Mono (rendered to hard 1-bit strikes) | Red Hat / Liberation Fonts project | SIL Open Font License 1.1 |

`port/fontdata_classic.h` holds the Chicago and Geneva 9 glyphs converted to bitmaps (generated by `port/gen/genfont_local.py`); `port/fontdata.h` holds the Liberation strikes (generated by `port/gen/genfont.py`). The converted bitmaps are derivative works of the fonts above and carry the same credit requirements: **Geneva 9 by Kelsey Higham (CC BY 3.0, via FontStruct); ChicagoFLF by Robin Casady.**

To override with your own pixel fonts, put `ChicagoFLF.ttf` / `geneva_9.ttf` (or a .zip containing them) in a `fonts/` folder at the top of the repo and run `./build_native.sh`; this writes `port/fontdata_local.h` (git-ignored), which takes precedence over `fontdata_classic.h`.

This is a summary, not legal advice; check the original font files' own license notes before redistributing them.
